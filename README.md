## 🚀 About The Project

**Luma** is a modern, visually striking landing page built to showcase high-performance digital marketing solutions. Serving as my **first Vue app**, this project demonstrates a firm grasp of component-based architecture, modern styling techniques, and lightning-fast tooling.

The application features a sleek dark theme paired with neon green accents, 3D isometric graphics, and a smooth, responsive user interface designed to capture attention and drive conversions.
